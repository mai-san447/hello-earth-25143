## 機能以外の要件

| ID | 要件 | どう守っているか |
| --- | --- | --- |
| N01 | 願いの中身を外に送らない | 願いは IndexedDB だけ。サーバーに出るのは信号の軌道IDと時刻、人の番号の発行のための軌道IDと発行時刻、本人が押したときの願いの絵（AI）のための言葉（保存しない）、それに本人が「星空に流す」を選んだ言葉（F19・F21）だけ。流した言葉の返し方に、軌道ID・状態・通報数は含めない |
| N02 | ネットがなくても止まらない | Service Worker、同梱データ、部品の読み込み失敗時の案内 |
| N03 | 利用者を責めない | 文言の方針（AGENTS.md）、「軌道へ戻す」を止めない |
| N04 | 変更で壊さない | テスト73件（2026-09-30）、CI、独立レビュー、Review guidelines |
| N05 | 戻せる | 手動公開と `wrangler rollback`（README） |
