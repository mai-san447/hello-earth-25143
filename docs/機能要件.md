## 機能以外の要件

| ID | 要件 | どう守っているか |
| --- | --- | --- |
| N01 | 願いの中身を外に送らない | 願いは IndexedDB だけ。ふだんの使い方でサーバーに出るのは、人の番号の発行のための軌道IDと発行時刻（`POST /api/orbits`）だけ。願いの絵（AI）はやめ、言葉はどこにも送らない。みんなの星（F19・F21）は次期バージョンで止めていて、止めている間は問い合わせもしない |
| N02 | ネットがなくても止まらない | Service Worker、同梱データ、部品の読み込み失敗時の案内 |
| N03 | 利用者を責めない | 文言の方針（AGENTS.md）、「もう少し預ける」を止めない |
| N04 | 変更で壊さない | テスト144件（2026-10-07）、CI、独立レビュー、Review guidelines |
| N05 | 戻せる | 手動公開と `wrangler rollback`（README） |
