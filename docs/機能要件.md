# MORUNE 25143 機能要件

更新：2026-09-30　関連：`docs/状態設計.md`、`docs/ユーザーフロー.md`、`docs/画面仕様.md`、`docs/検証計画.md`

状態の見方：**済**＝実装して本番公開、**確認待ち**＝本番公開済みでスマホ実機の確認が残る、**停止**＝コードはあるが本番では動かしていない、**未**＝まだ作っていない

## 使う人

| 人 | 場面 |
| --- | --- |
| 本人（入院・治療中） | 入院前に家で預ける／病室（ネットなし）で思いついたら足す・眺める／退院後に1つずつ帰す |
| 応援する人（家族・友人） | 会えない間に、応援リンクから信号を送る |

## 機能以外の要件

| ID | 要件 | どう守っているか |
| --- | --- | --- |
| N01 | 願いの中身を外に送らない | 願いは IndexedDB だけ。サーバーに出るのは信号の軌道IDと時刻だけ（AGENTS.md の守ること） |
| N02 | ネットがなくても止まらない | Service Worker、同梱データ、部品の読み込み失敗時の案内 |
| N03 | 利用者を責めない | 文言の方針（AGENTS.md）、「軌道へ戻す」を止めない |
| N04 | 変更で壊さない | テスト42件、CI、独立レビュー、Review guidelines |
| N05 | 戻せる | 手動公開と `wrangler rollback`（README） |
