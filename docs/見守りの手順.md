# みんなの星空の見守りの手順

## 見守りとは

みんなの星空に出る言葉を、人が見て、出してよいかを決める役目。願いは名前なしで公開されるので、個人情報・悪口・宣伝・つらい気持ちの言葉がまざることがある。MORUNE は、療養中など気持ちが弱っている人も使う前提なので、ここを丁寧にする。

## 自動でしていること（人がいなくても動く）

| しくみ | 中身 |
| --- | --- |
| 保留 | URL・メールアドレス・電話番号らしい数字・施設の名前らしい言葉・注意語（悪口、つらい気持ちの言葉など）を含む言葉は、すぐには出さず「保留」にする。保留の言葉は、人が「出す」を押すまで誰にも見えない |
| 通報 | 3人から通報された言葉は、自動で隠す |
| 一時停止 | 一時停止を入れると、新しく流された言葉は内容に関係なくすべて保留になる（見守れない期間用）。設定が読めないときも、安全のため一時停止として扱う |
| 本人の削除 | 書いた本人は、自分の言葉をいつでも消せる（他の人の言葉は消せない） |
| つらい言葉への案内 | 「死にたい」「消えたい」などを書いた人には、預けたあとに相談窓口（厚生労働省「まもろうよ こころ」）を端末の中だけで案内する。願いは送らない |

## 人がすること

| いつ | すること | 目安 |
| --- | --- | --- |
| 1日1回 | 見守り画面（`/watch`）で、保留と非表示の一覧を見る | 5分 |
| 保留の言葉 | 問題なければ「出す」。個人情報・悪口・宣伝なら「消す」。迷うものは保留のまま | ― |
| 非表示（通報）の言葉 | 通報が正しければ「消す」。いたずらの通報なら「出す」 | ― |
| 消してほしいと言われたら | 問い合わせフォームで受け付け、見守り画面で「消す」 | 受けてから3日以内 |
| つらい気持ちの言葉 | 公開はしない（保留のまま、または消す）。書いた人には、預けた時点で窓口の案内が出ている | ― |

保留の言葉は出ないだけなので、確認が少し遅れても害はない。急ぐのは、通報で隠れた言葉と、消してほしいという依頼。

## 見守れない期間（出張・療養・長い休みなど）

1. 見守り画面で「新しい言葉をすべて保留にする（一時停止）」を入れる
2. 期間中は、新しい言葉は星空に出ない。すでに出ている言葉と、通報で隠す仕組みはそのまま動く
3. 戻ったら、たまった保留を確認してから一時停止を外す
4. 長くなるときは、利用規約のお知らせ欄に「いまは新しい言葉の公開を止めています」と出す（任意）

展示の会場では、その場のスタッフが大きな画面を見守る。気になる言葉は、会場の PC の見守り画面から隠す。

## 見守り画面の入り方

- 画面：`https://morune-25143.morune-25143.workers.dev/watch`（アプリからはリンクしない。検索にも出さない）
- 合言葉：Cloudflare の Secret `WATCH_TOKEN`（16文字以上。まちがえられるのは全体で1分5回まで（同じ回線からの回数制限も重ねる））。作り方の例
  ```
  npx wrangler secret put WATCH_TOKEN --config wrangler.jsonc
  ```
  合言葉は、パスワード管理アプリだけに保存する。リポジトリ・メール・チャットに書かない
- 合言葉はブラウザのタブを閉じると消える（そのタブの中だけに保存）
