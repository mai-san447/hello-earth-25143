# 北極中心の星図（feat/polar-sky、2026-10-07）

目的：東京の10月深夜など、北斗七星が低くなる時間にも願いの星が画面外へ消えないようにする。

進め方：投影を sky.js に集める → 恒星・願い・星座線を共通の投影にする → 飛行と退避表示を確認する → 全テスト・lint・型チェック。

受け入れ条件：天の北極が中心、赤緯40度の星が短辺45%の円内、地方恒星時で反時計回り、下の南中が地平線側。3星座と30個の願いが季節・時刻・位置・縦横比によらず画面内。地平線下も消さない。完成した線・上昇・帰還・帯の文言・オフライン動作を維持する。

実装：Three の恒星を共通の投影からクリップ座標に変換し、透視カメラの影響を外す。フラスタムの除外も使わない。青白・白・淡黄の色と遅いまたたきを維持。Canvas 2D の退避表示も同じ位置・色・またたき。重なる願いのずれは最大8pxにして、長期間使っても画面外へ広がらないようにした。イトカワの実方向の印は従来の固定視線で描く。

確認：`node --test --experimental-test-isolation=none tests/*.test.mjs` で122件成功。投影・不正値・12か月×24時刻×3地点×4画面サイズ、背景と願いの一致、リサイズ・時刻更新、地平線下の線、同じ位置への飛行を確認。既存テストの描画入力は旧高度方位の仮データから本物の投影データへ変更し、線数と飛行の検証を維持した。`npm run lint` はエラー0・既存警告5件。`npx tsc --noEmit -p .` 成功。

残る確認：標準の `npm test` は Node のテスト子プロセス起動が `spawn EPERM` で拒否される。開発サーバーも Vite の設定読み込み中に同じ制限で停止した。制限のない環境で標準コマンドとブラウザ・スマホの実画面を確認する必要がある。環境制限だけを理由にプロジェクトのテスト実行方法は変更していない。
