# 類似サービス調査（2026-09-30）

関連：`docs/みんなの星_設計.md`、Issue #22〜#27

## うまくいった例

| サービス | 何をしたか | うまくいった理由 | MORUNE 25143 に取り入れること |
| --- | --- | --- | --- |
| **Kind Words**（ゲーム） | 悩みを匿名の手紙で送り、見知らぬ人がやさしい返事を書く | 最初に「荒らしは歓迎しない」と約束させる。フォロワーも「いいね」もない。キーワードで自動検知されるのは全体の約3％で、残りは人の目と強い約束ごとで守る。安い有料で、使い捨ての荒らしを防ぐ | 公開の前に「やさしい言葉だけ」を約束する。数を競う仕組みを置かない。自動の確認＋通報＋人の確認 |
| **Journey**（ゲーム） | 知らない人と一緒に旅をする。言葉はなく、音（チャープ）だけで交流 | 伝え合える手段をわざと1つに絞った。相手を助けると自分も進める | 他の人の星への反応は、言葉ではなく「応援の信号」だけにする（返信は作らない） |
| **ひとりぼっち惑星**（ゲーム） | 集めた「こえ」＝知らない誰かの短いメッセージを受信し、自分も送る | 誰かの言葉がふと届く、一方通行の静かなつながり。SNS で広がった | 他の人の星から、ときどき短い言葉が届く。ただし運営が使っていたクラウドの終了で送受信が一時止まった → データの置き場所と書き出しを自分で持つ |
| **はやぶさ ミリオンキャンペーン** | 名前をアルミ箔に刻み、ターゲットマーカーでイトカワへ | 約88万人（149か国）が参加（はやぶさ2では約41万人）。本物の探査機に自分の一部が乗る | イトカワ・はやぶさの物語そのもの。2026年も はやぶさ2 がメッセージを募集し「探査18きっぷ」を発行している |
| **NASA Send Your Name** | 名前を探査機に載せ、記念の「搭乗券」を発行 | Artemis I で170万人以上。持ち帰れる記念品（搭乗券）が共有を生む | 願いが帰ってきたら「帰還証明書」（共有できるカード）を出す |
| **FutureMe** | 未来の自分に手紙を送る | 20年以上続き、手紙は数百万通。運用費は月500ドルほどで、話題になるまで続けられた | 時間をおいて届くこと自体に価値がある。運用費を小さく保ち、長く続けられる作りにする |
| **Slowly** | 手紙が、相手との距離に応じて時間をかけて届く | 「遅さ」を価値にした。2019年に140万人 | **本物の距離から、光の速さで届くまでの時間を演出にする**（イトカワまで約2.7億km＝光で約15分） |

## うまくいかなかった例

| サービス | 何が起きたか | 避けること |
| --- | --- | --- |
| **Yik Yak** | 匿名で近くの人に投稿できる。一時は約4億ドルの評価だったが、いじめ・脅迫が相次ぎ2017年に終了 | 匿名で、誰にでも、自由に返信できる形。場所で絞った見せ方 |
| **Secret** | 匿名で秘密を投稿。約1億ドルの評価から16か月で終了（嫌がらせ） | 同上。守る仕組みより先に広げること |
| **星の命名の販売**（International Star Registry など） | 星に名前を付けられると売るが、国際天文学連合（IAU）は認めておらず「実質的な詐欺」と批判されている | 枝番やキーホルダーで「星に公式の名前が付く」と誤解させること。作品の中の番号だと明記する |
| **やりたいこと・目標のアプリ全般** | 生活や心のアプリは、100日以内に中央値で約70％が使わなくなる。最初の1週間で習慣にならないと離れる | 使い始めに価値が見えないこと。リストが重荷になること |

## 最新の宇宙の話題（作品の物語と本物のデータに使える）

- **はやぶさ2、トリフネのフライバイに成功**（2026-07-05）。中心から約800mを秒速約5kmで通過し、画像の取得に成功。次は2031年に小惑星 1998 KY26（幅約11m）へ
- **はやぶさ2 ミリオンキャンペーン2♯ 第2回**：探査機に届けるメッセージを 2026-04-07〜**09-30** に募集。「探査18きっぷ」で拡張ミッション全体の旅程をスタンプで見せる
- **中国の天問2号**が小惑星カモオアレワに到着（2026年7月）。2027年11月にサンプルを地球へ届ける予定。カモオアレワの表面は**イトカワに近い成分**という研究も出ている
- サンプルリターン（行って、持ち帰る）は今も続く人類の挑戦。MORUNE 25143 の「預けて、帰ってくる」と重なる

## 設計の原則（ここから導いたこと）

1. **やさしい場を先に作ってから広げる**（Kind Words／Yik Yak）：公開の前の約束、自動の確認、通報、人の確認を最初から入れる
2. **伝え合う手段を絞る**（Journey）：他の人への反応は「応援の信号」だけ。返信・フォロー・いいねの数は作らない
3. **遅さと距離を価値にする**（Slowly／FutureMe）：本物の距離から、光の速さで届く時間を出す
4. **持ち帰れる記念を渡す**（NASA／JAXA）：帰還証明書、旅のスタンプ
5. **公式だと誤解させない**（星の命名の販売）：枝番は作品の中の番号。IAU や JAXA とは関係ないと明記する
6. **最初の1回で価値を見せる**（目標アプリの離脱）：はじめて預けた願いが、その場で1つ帰ってくる体験をすぐに
7. **置き場所を自分で持つ**（ひとりぼっち惑星）：データは Cloudflare D1。書き出しの手順を持つ
