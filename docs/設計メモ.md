# 25143｜1日版 設計メモ

## 一文でいうと
小惑星25143イトカワのサンプルリターンになぞらえ、治療や旅立ちの前に「帰ってきたら、したいこと」を声で未来へ預け、帰還した声として聴き直す体験。

## 完成条件
- 願いを1行入力できる
- 30秒以内の録音ができる
- スマホを振る、または「落とす」を押すと帰還演出が始まる
- 録音した自分の声を再生できる
- 録音を外部送信・永続保存しない

## ユーザーフロー
入力 → 録音 → シェイク／落下 → 帰還演出 → 再生

## 評価基準への対応
| 観点 | 作品で見せること |
|---|---|
| テーマ愛 | はやぶさのサンプルリターンを「人生の帰還」へ翻訳 |
| UX | 考える・話す・振る・聴く、という短い身体的体験 |
| 技術挑戦 | MediaRecorder、DeviceMotion、非対応時のフォールバック |
| オリジナリティ | 未来へ送るだけでなく、未来から声が帰ってくる |

## あえて作らないもの
- 会員登録
- クラウド保存
- SNS共有
- AI音声変換
- ハードウェア連携

## デモの核
「自分の声が未来から戻る」瞬間を、実演で見せる。
