# 25143｜1日版 設計メモ

> この文書は 2026-09-26 のハッカソン「1日版」の記録です。今の設計（選択肢は3つ、帰還が始まる日、オフライン、星座、応援の信号）は [状態設計](状態設計.md) を見てください。


小惑星25143イトカワからのサンプルリターンを、未来の自分へ預けた願いが地球に帰ってくる体験に重ねる。

## 完成条件

- 入力欄ひとつで複数の願いを文字として端末内に預けられる。スマホ標準のキーボード音声入力も利用できる。
- スマホを振るか代替ボタンを押すと、待機中の願いが1件だけ帰還する。
- 内容や声を確認し、4つの判断を保存できる。
- 判断後にはやぶさがイトカワへ戻り、次を呼べる。
- ブラウザを閉じて開き直しても願いが残る。
- スマホでは宇宙の航路と帰還アニメーションを画面上部に残し、入力・判断・履歴のみ下側でスクロールする。

## 審査基準との対応

| 観点 | 見せること |
|---|---|
| テーマ愛 | サンプルリターンを「人生の帰還」として再解釈 |
| UX | 遠いイトカワへ預ける・振る・帰還を待つ・選ぶ、という身体的な体験 |
| 技術挑戦 | 端末の動き、端末内保存、状態遷移、フォールバックと航路のアニメーション |
| 独自性 | 未来へ送った願いが1件ずつ帰り、今の自分が向き合う |

詳細は[処理フロー](処理フロー.md)。

## 1日版で扱わないこと

ログイン、端末間同期、アプリ独自の音声入力・録音保存、取り組み中の再編集、クラウド保存。

## デザインの次の判断

現段階は宇宙の距離と帰還の動きを主役にする。ピクセルアート等の表現スタイルは、スマホ実機で体験の読みやすさと没入感を確認した後に比較する。提出までの必須機能を優先し、見た目だけを先に作り直さない。
