# わたしの星空と、みんなの星空（2026-10-12 本人と決定）

## 決めたこと

画面を2つに分ける。

| | わたしの星空（いつもの画面） | みんなの星空（別の画面） |
| --- | --- | --- |
| 役割 | 預ける・待つ・1つ帰ってくる | いろんな人の願いを見に行く |
| 見えるもの | 自分の19の星（北の星座の席）。他の人の星は背景の淡い光だけで、触れても言葉は出ない | 名前なしの、みんなの願い。自分の公開した星もその中に光る。自分だけの星は出ない |
| 操作 | 振る（ガチャ）・ひとつ帰す・星をタップして「帰す」 | 3Dで見回す・近づくと言葉が読める |
| 展示 | 来場者のスマホ | 会場の大きな画面にもそのまま使う |

行き来：画面の上に「わたしの星空／みんなの星空」の切り替えを1つ置く。

## なぜ分けるか

- **タップの取り違え**：スマホでは他の人の星が自分の星の24px以内に平均5.5個入る（シミュレーション）。わたしの星空で他の人の星に触れられなくすれば、取り違えがなくなる
- **公開か自分だけかの見分け**：みんなの星空に出るのは公開した星だけなので、違いが場所で分かる
- **シンプルさ**：毎日開く画面は「預けて、帰ってくる」だけにする。3Dの重さと操作の多さは、みんなの星空の中に閉じこめる
- 「星空はみんなの願いでできている」は、わたしの星空の淡い光と、みんなの星空の両方で残す

## みんなの星空の段階

| 段階 | できること | 目安 |
| --- | --- | --- |
| 1 見回す | 指でなぞると空が回り、つまむと寄れる | 2〜3日 |
| 2 近づくと読める | 遠くは光だけ、寄ると近くの言葉が浮かぶ。見える範囲の星をサーバーから取る | +2〜3日 |
| 3 飛んで行く | 本物の星の距離を奥行きにして、宇宙の奥へ進む | 1〜2週間 |

GGA セレクション（2026-10-14）のあとに段階1から試作し、手ざわりを見て段階2へ進むか決める。

## 気をつけること

- 見せる願いが増えるほど、見守り（保留の確認・通報）の手間が増える。展示ではスタッフが見守る
- スマホでの重さ・電池・熱。段階3は展示の大きな画面を先に考える
- 星の名前や距離（例：ドゥーベ・123光年）は画面に出さない（2026-10-12 本人の判断）

## 公開のしかた（2026-10-12 本人と決定）

- **初期値は「自分だけ」**。出してよいものだけ、自分で選んで公開する（10/11 の「初期値は出す」から変更）
- 公開できる場面と、みんなの星空での見え方：

| 願いの段階 | みんなの星空での見え方 | 公開の選び方 |
| --- | --- | --- |
| 預けた | 淡い星 | 預けるときに「みんなの星空に出す」を自分で選んだときだけ |
| やってみることにした（受け取った） | 明るい星 | 帰還票の画面で「みんなの星空に出す」を選べる。**中心の場面** |
| 叶った | 流れ星 | 今の「叶ったよ」のまま |

- 「みんなの星空に出す前に」の約束は、自分で公開を選んだときにだけ出す（同意したら二度と出さない）
- いま公開されている願いは、そのまま公開のまま。初期値が変わるのは、これから預ける願いだけ
- 見本の願いを作って空を埋めることはしない。数は展示（会場で預けた人が、その場で公開を選ぶ）で増やす

## ハートを送る（2026-10-12 本人と決定）

- みんなの星空に公開された願いの星（預けた・やってみる）に、見た人がハートを送れる。「叶ったよ」の流れ星には送れない（持ち主の願いとつながらず、数を届ける先がないため。2026-10-12 レビューで実装に合わせた）。送れるのは番号を発行した端末だけ
- 押すと、その星から小さなハートの光がふわっと浮かぶ
- **数は願いの持ち主にだけ届く**（回収記録・帰還票に「♡ ×12」）。他の人には数を見せない。多い・少ないで比べられないようにするため（「比べる数は持たない」の決まり）
- 1台の端末から同じ星へは1日1回まで。誰が送ったかは記録しない（数だけ）
- 言葉は書けない（返信・コメントは作らない）
- X のいいねはアプリの外、ハートはみんなの星空の中、と場所で分ける（10/7 に応援の信号をやめた理由と重ならないように）

## 実装（2026-10-12、ブランチ feat/nineteen-seats、本番未反映）

- みんなの星空：public/everyone-sky.js。天球（半径1）を立体射影で写す。立体射影は角度を保つので、画面の端でも星の並びの形がゆがまない（テストで確かめた）。視野は24〜100度、48度より狭いと中心に近い言葉を最大4つ出す
- 置き場所：PublicStars.sphereSeed。天球に偏りなく散らす（赤緯は sin が一様。極に集まらない）
- 段階：預けた（淡い）／やってみることにした（明るい・1年）／叶った（流れ星・24時間）。帰還は「受け取る」を選んだときに送り、着地しただけでは変えない
- ハート：日付・軌道ID・星を HEART_SECRET で混ぜた値（HMAC-SHA256）で1日1回を数え、3日で消す。番号を発行した端末だけ、1つの星に1日200まで。数は持ち主だけが回収記録で見る（帰還票には印字しない）
- わたしの星空：他の人の星は淡い光だけで触れない。みんなの星空に出した自分の星は十字の光、自分だけの星は丸い光（案1）
- パソコン：星図を右に寄せ、願いの星の円（短辺の36.6%）を見出しと操作バーの間に収める

## 本番に出す手順（順番を守る）

1. 本番の D1 に表を足す（古いコードは新しい列があっても動く。逆に、表より先にコードを出すと、みんなの星がすべて 503 になる）
   `npx wrangler d1 execute morune-25143 --remote --file drizzle/0008_stage_hearts.sql --config wrangler.jsonc`
2. ハートの鍵を入れる（32文字以上の乱数。控えはパスワード管理アプリへ。入れなければハートは出ない）
   `npx wrangler secret put HEART_SECRET --config wrangler.jsonc`
3. `npm run build` → `npx wrangler deploy --config wrangler.jsonc`。戻すときは `npx wrangler rollback`
4. 本番で確かめる：みんなの星空が開く／自分だけの願いで約束が出ない／帰還票の「みんなの星空に出す」／ハート（別の端末から）／回収記録の数
