### 気づいて直したこと（ボーイスカウト）

- 「アーカイブに保存」した願いが一覧で「完了」と出ていた → 「アーカイブ」に（ボタン名とそろえる）
- みんなの星は、D1 はあるが表が無いと 503 になり、意図して止めているのか障害なのか区別できなかった → `PUBLIC_STARS_ENABLED` が `"true"` のときだけ開く（本番は `"false"`）。応援の信号は止めない
- 手元の開発サーバーでは、応援の信号の API が 503 を返す（手元の D1 に signals 表が無い）。既存の状態で、本番には影響しない。手元で試すときは README の手順で表を作る

### 残っている技術的負債

- ログイン同期（本番では停止中）は、育つ記録（`steps`・`firstStep`・`fulfilledAt`）を保存しない。`returnFrom` と同じ扱い
