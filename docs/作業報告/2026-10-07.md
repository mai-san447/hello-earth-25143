## リリース前レビュー（Claude と Codex、読み取りのみ）

指摘は全件直して本番に出した。主なもの：

- Service Worker：`pageKey('/')` が例外になり、オフライン用の保存が最初から失敗していた → 直した（テスト追加）。5xx のときは保存した版を出す
- `/api/art`：画面から外しても外から呼べば AI が動いた → `ART_ENABLED` で既定停止
- みんなの星：止めているのに開くたびに軌道ID を送っていた → 送らない
- 利用規約：止めた機能の説明・古い一文が残っていた → 今の動きに合わせて書き直し、X でのシェア・番号の節を足した
- 30個のとき、判断待ちのカプセルを数えず31個になった → 枠に数える（テスト追加）
- 試しの帰還の途中で再読み込みすると試せなくなった → 帰還の保存が成功してから記録
- 帰還票の一歩の保存に失敗しても画像が出た → 止めてエラーを出す
- 帰還票を後日つくり直すと帰ってきた日が変わった → `returnedAt` を保存
- API のログに外部例外の本文が出うる → エラーの種類だけを出す（`app/api/error-kind.mjs`）
- 文言：「送信完了」「手放す」「アーカイブ」→ 今の動きに合わせた。英字の見出しを外した。小さく薄い文字を 12px 以上に。呼び名を「回収記録」「帰還票」にそろえた
- 使いやすさ：回収記録を開いている間は下の操作バーを `inert`、帰還票の画面に × と Tab の閉じ込め
