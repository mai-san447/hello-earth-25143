# 2026-10-06 メンター会メモ

## メンターの見立て

- 前回の宿題「物理にこだわる」への答えとして、帰還証明書に行き着いたのはよい。ベースはもう良い
- 今の証明書のデザインは「一昔前の占いの鑑定書」に見える。もらって嬉しい1枚にしたい
- **イベントで使うなら、感熱式のロールプリンター**（店舗用。スター精密のオーダープリンターなど、壊れにくい。5万円前後）で、その場で出てきた紙をちぎって渡す体験ができる
- 参考：韓国で、感熱紙にあえてモノクロ・粗い写真を印刷するのが流行っている。画質より「その瞬間を一緒に楽しむ」（プリクラの代わり）
- **願いの内容から絵を作る**（例：「サイパンに行く」ならサイパンの絵）。作り方の案：
  1. 基準になる絵を1枚決め、その画風を AI になるべく長い言葉で言語化させる
  2. 画風は固定、願いのキーワードだけ変えて画像を作る（画像生成の API を後ろにつなぐ）
  3. 写実に寄せると不気味の谷に入るので、最初から漫画・アニメ・イラストに寄せる
- **企画書に「物」の企画を入れておけば、かなり良い**（いま物を作り切らなくてよい）。企業とのコラボや催し物（ガツガツした売り物ではない形）も考えられる
- 応援の形は、使う集団（スポーツ、病院など）で変わる。病院向けに、寄せ書きのような物を届ける案（病院のテレビカードを買うより喜ばれる）
- 病院の白い壁は気分を下げる。自然素材・緑・木目が安心につながる（ただし、この作品は宇宙なので、そこまでこだわらなくてよい）
