# 本物の星座でウィッシュリスト（#28 v3）

試作：https://claude.ai/artifact/LzPcFt9b24LDV4CsaNvjiJ （`docs/prototypes/2026-10-02-real-constellation.html`）

## なぜ作り直すか

v2（MORUNE オリジナルの形：帰り道座など）への本人の感想は「やってみたい・楽しいがない。リアリティが薄い」。
v3 では、形も名前も**本物の星座**にする。本物なので、次の3つができる。

1. **なぞる**：帰ってきた願いを受け取ったら、前の星から次の星まで指でなぞって線をつなぐ。手でつなぐひと手間を楽しさにする。
2. **知る**：灯った星には本当の名前・明るさ・距離がある。「この光は 1903 年に星を出た光です」と、光の時間（#26）につながる。
3. **見上げる**：完成した星座が、今夜の空のどこにあるか（方角と高さ）がわかる。病室の窓から本物を探せる。

物語：**軌道にいる間はイトカワに預けたサンプル。帰ってきたら、地球から見える本物の星にとまる。**
（「サンプルはイトカワの上にあるはず」という矛盾も、v2 と同じこの説明で解ける）

## 流れ

| 段階 | 本人がすること | 画面に出るもの |
| --- | --- | --- |
| 1 星座をえらぶ | 願いの数（3〜7）で星座をえらぶ | 各星座に「今夜 21時ごろから見える／見ごろは1月」 |
| 2 願いを預ける | 呼び名（例：退院したらやりたいこと）と願いを書いて預ける | 星図は点線の円だけ（まだ灯っていない） |
| 3 帰ってきたら、なぞる | 帰った願いを決める → 前の星から次の星へ指でなぞる | 星が灯り、星のカード（名前・距離・光が出た年・ひとこと） |
| 4 今夜の空で探す | 全部灯ると完成 | 方角と高さの図、「北東の空、高さ 53°」 |

### 決めごと

- **どれが帰るかは選べない**（今のアプリと同じ）。**どの星が灯るかは決まっている**（星の並び順）。だから線はいつも前の星とつながり、形が少しずつ見えてくる。
- **灯る**のは「これやろう」「もう叶った・対応済み」「もう用済み」。**手放せた願いも星になる**。色で分ける（金・青白・灰）。
- 「いまはいいや」は軌道へ戻る。星は灯らない。
- なぞれない人のために「なぞらずに線をつなぐ」ボタンを必ず置く（片手・点滴中・視覚の不安）。最初の星はタップだけ。
- 位置情報は使わない。方角と高さは**東京で計算**（国内ならほぼ同じ向き）。オフラインでも計算できる。

## えらべる星座（最初の5つ）

願いの数 3〜7 に1つずつ。明るく、街なかや病室の窓からでも見つけやすいものを選んだ。

| 願いの数 | 星座 | 見ごろ（宵） | えらんだ理由 |
| --- | --- | --- | --- |
| 3 | 夏の大三角 | 8月 | 七夕の織姫・彦星＝**願いの星**。コピー「願いを星に」（#13）と合う |
| 4 | 秋の四辺形 | 10月 | 提出〜GGA の時期に見える |
| 5 | カシオペヤ座 | 11月（北の空・一年中） | 一年中見える。W の形がわかりやすい |
| 6 | 冬のダイヤモンド | 1月 | 1等星6つ。いちばん明るい |
| 7 | 北斗七星 | 5月（北の空） | 7つ＝1週間。v2 の「7つで完成」を引き継ぐ |

「星の並び（アステリズム）」も入れている。画面では「星座」と「星の並び」を書き分ける（正確さのため）。

## データ

- 星：赤経・赤緯・等級・距離（光年）・ひとこと。**Yale Bright Star Catalog（パブリックドメイン）と理科年表で確かめて入れる**。試作の値は概数。
- 星の名前：IAU が決めた固有名（ベガ・ドゥーベなど）と日本の呼び名。事実なので権利の問題はない（`docs/権利の確認.md` に追記する）。
- 星座の線：自分で決めて書く（他のソフトの線データはコピーしない）。
- 遠い星（デネブ・リゲル・ツィー）は距離の幅が大きいので「約」をつけ、ひとことで説明する。
- 背景の星：試作は乱数。実装では星表の 4.5 等より明るい星を、星座のまわりだけ持つ（数十〜百個、数KB）。

## 今のアプリとの関係

| もの | どうするか |
| --- | --- |
| 1件ずつ預ける今の流れ | 残す。「星座で預ける」はもう1つの入口 |
| 回収記録の星座（言葉の近さ・Prim 法、F09） | 残す。1件ずつ預けた願いはこちら |
| 状態 waiting/doing/done/expired | そのまま使う。星座には「どの星座か」「何番目の星か」を足すだけ |
| 帰還証明書（#26） | 完成した星座の図と「今夜の方角」を入れた**星座の証明書**を足す |
| 応援の信号（F10） | 灯った星が明るくなる（今の仕組みのまま） |
| みんなの星（#22） | 星座は公開しない（願いの言葉がまとまって出るため）。将来の検討 |
| 保存 | 端末の中だけ。サーバーに送るものは増えない |

## 10/7 の提出に入れる範囲

提出まで5日。発表まわりの作業が残っているので、**1日で作れる範囲**に切る。

**入れる（P0）**
- 5つの星座、星のデータ、なぞる、なぞらずにつなぐ
- 星のカード（名前・距離・光が出た年・ひとこと）
- 完成画面の「今夜の方角と高さ」
- テスト：高さと方角の計算（北極星が高さ約36°・方角が北）、灯る順番、0h をまたぐ星座の中心

**GGA に回す（P1〜P2）**
- 星座の証明書（画像）
- 背景を星表の本物の星に
- 今夜の空での向き（星座を、実際に見える傾きで回して描く）
- 星座をもっと増やす（オリオン座・さそり座など。星の数が多いので「7つまで」の決まりを見直す）
- スマホを空にかざすと方向がわかる（端末の向きセンサー）

## 確かめたいこと（#20 の検証に足す）

- 「なぞる」は楽しいか、面倒か（5人に試してもらい、なぞるボタンとつなぐボタンのどちらを押したか数える）
- 完成したあと、実際に窓や外で空を見たか（聞くだけ）
