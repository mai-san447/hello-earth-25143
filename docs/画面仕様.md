# MORUNE 25143 画面仕様・UIデザイン仕様

更新：2026-09-30　画面の骨組みは `app/mission-experience.tsx`、動きは `public/mission.js`、見た目は `public/style.css`

## 画面の一覧

| 画面 | 目的 | 主な要素 | 状態・エラー時 |
| --- | --- | --- | --- |
| スプラッシュ | 起動の間を埋める | タイトル | 2秒で消える。部品を読めないときは消えて「再読み込みしてください」 |
| 位置情報の確認 | 星空を現在地に合わせるか選ぶ | 許可／位置情報なしで見る | 許可しなくても使える。取得できなければその旨を出して続ける |
| ミッション画面（トップ） | 宇宙を眺め、操作の入口 | 見出し「願いを星に、想いを地球へ。」、3D星空とイトカワ（名札に距離）、軌道の星、通信表示、下のパネル（01 送信／02 帰還／03 受け取り） | ネットなしのとき「ネットなし · 願いはこの端末の中で預かります」 |
| 01 送信（預ける画面） | 願いを預ける | 60字の入力欄、帰還が始まる日（任意・翌日〜1年後）、「名前を出さずに星空に流す」（みんなの星が使えるときだけ・初期値は流さない）、星を軌道へ送る | 空欄→聞き返し。軌道が30個→預けず入力を残す。日付が範囲外→理由を出す |
| 02 帰還 | 1つ帰す | 振る／タップで帰還 | 軌道が空→「すべての願いは地球にあります」。開始日前だけ→「○月○日から」。判断待ちがある→「先にカプセルを開いて」 |
| 03 受け取り（カプセル） | 帰ってきた願いと向き合う | 願いの言葉、預けた日、待っていた日数、イトカワまでの距離、届いた信号の数、3つの選択、Xで共有 | 選ばずに閉じてもカプセルは残る。保存に失敗→「もう一度お試しください」 |
| 回収記録 | 帰ってきた願いを見返す | 一覧、星座、応援リンク（信号が使えるときだけ）、あなたの記録（数とコピー）、削除・リセット | 削除とリセットは確認してから |
| 利用規約・プライバシー | 何を保存・送信するかを伝える | 保存、端末への保存、応援の信号、みんなの星（匿名の公開）、位置情報、外部サービス、ルール | — |
| 約束（みんなの星） | はじめて流す前に同意してもらう | 3つの約束、約束して流す／今は流さない | 同意しないと流せない。Esc で閉じると「流さない」 |
| 他の人の星のカード | 他の人の言葉を読む | 言葉、応援の信号を送る、通報（確かめてから送る） | できるのは信号と通報だけ。返信・いいねの数はない |
| 叶ったよ | 受け取ったあと、任意でひとことを流す | 40字の入力、流れ星にして流す／今は流さない | 空欄は聞き返す。流せたら「閉じる」だけにする |
| 応援ページ（/signal） | 応援する人が信号を送る | 約束（名前も言葉も届かない）、光る星、信号を送る | リンク不正・未対応・混雑・今日はもう送った、をそれぞれ別の文言で |

## 画面の4つの状態（空・エラー・処理中・成功）

画面を作るときの定番の確認。2026-09-30 に全画面を点検した（Issue #21）。「—」はその状態がない画面。

| 画面・操作 | 空 | エラー | 処理中 | 成功 |
| --- | --- | --- | --- | --- |
| 起動 | — | 部品を読めない→「再読み込みしてください」／保存を読めない→理由を表示 | スプラッシュ | 通信表示が消えて操作できる |
| 位置情報 | — | 非対応・取得失敗→「位置情報なしで続けられます」 | 「現在地を確認しています…」 | 「星空を現在地に合わせました」 |
| 3D星空 | — | 読めない→「簡易表示で続けます」 | — | 3D表示 |
| 預ける | 空欄→聞き返し | 30個・日付の範囲外・保存失敗→理由と入力を残す | **「星を送っています…」（今回追加）**、ボタンを止める | 「送信完了」 |
| 帰還 | 軌道が空／開始日前だけ→案内 | 帰還記録を保存できない→「通信を確認してください」 | 帰還飛行の演出、次の帰還を止める | カプセルが着地 |
| カプセルで選ぶ | — | 保存失敗／選び直せない状態→別々の文言 | ボタンを止める | 星座に加わった／軌道へ戻した |
| 回収記録 | 「まだ帰還した願いはありません」 | 削除・リセット失敗→理由 | ボタンを止める | 「○件の願いを削除しました」 |
| 星座 | 1個以下→「受け取るたびに育っていきます」 | — | — | 星と線 |
| 応援リンクを送る | — | 共有できない→リンクを表示 | — | 「共有シートを開きました」／「コピーしました」 |
| あなたの記録 | 0 の数を表示 | コピー失敗→「書き写して渡してください」 | — | 「コピーしました」 |
| 応援ページ | — | リンク不正・未対応・混雑・今日は送った、を別の文言で | **「星の様子を確かめています…」「信号を送っています…」（今回追加）** | 「信号を送りました」 |
| 他の人の星（星空） | 星がない→描かない、「みんなの星」ボタンも出さない | 読めない→端末に控えた星を出す。機能がない環境→すべて隠す | 裏で受け取る（画面は止めない） | 青白い星と流れ星、ボタンに数 |
| 星空に流す（預けると同時） | — | 上限・保存失敗→理由（願いは端末に預け済み）。ネットなし→「Wi-Fi につながったら流せます」 | 預ける演出のあとに結果を出す | 「星空に流しました。あなたの番号 25143-XXXX」／保留→「確かめてから星空に出します」 |
| 他の人の星のカード | — | ネットなし→「Wi-Fi につながったら送れます／通報できます」。もう空にない星→「もう空にありません」 | 「信号を送っています…」「通報を送っています…」、ボタンを止める | 「信号を送りました」「通報を受け付けました」 |
| 叶ったよ | 空欄→聞き返し | 上限→理由と入力を残す。ネットなし→控えて案内 | 「流れ星にしています…」 | 「『叶ったよ』を流れ星にしました」 |

## UIデザイン仕様

### 色

夜空の中で、金色を「願い・操作の中心」に使う。

| 役割 | 色 |
| --- | --- |
| 背景（夜空） | `#050812` 〜 `#101a25` のグラデーション |
| 主な操作・願いの光 | 金 `#e6c878`、`#edc45c`、光 `#fff1ce` |
| 他の人の星（みんなの星） | 青白 `#d8e9ff`、光 `#8fc1ff`、ボタン `#9cc8ff`（自分の金と混ざらないように） |
| 本文 | `#e8e6dc`、`#e4e8df` |
| 補足 | `#98a7a9`、`#aebcba` |
| フォーカス | `#edcb8c` の2pxの枠 |

### 文字

- 本文：Zen Kaku Gothic New（ない端末は sans-serif）
- 願いの言葉・見出し：明朝（Yu Mincho、Hiragino Mincho ProN）
- 英字のラベル（WISH CAPSULE など）：Inter、字間を広げる
- 入力欄は16px以上（iPhone で拡大されないため）

### 操作

- 押せるものは44px以上の高さ
- 動きを減らす設定（prefers-reduced-motion）のときは、演出を止めるか短くする
- スマホの安全領域（ノッチ・ホームバー）を避ける
- 振る操作ができない端末には、必ずタップの代わりを用意する

### 文言

- 利用者を責めない。「まだ」「失敗」より「今でなくてもいい」「また明日」
- エラーは、何が起きたかと、どうすればよいかを1文で
