# MORUNE 25143 画面仕様・UIデザイン仕様

更新：2026-09-30　画面の骨組みは `app/mission-experience.tsx`、動きは `public/mission.js`、見た目は `public/style.css`

## 画面の一覧

| 画面 | 目的 | 主な要素 | 状態・エラー時 |
| --- | --- | --- | --- |
| スプラッシュ | 起動の間を埋める | タイトル | 2秒で消える。部品を読めないときは消えて「再読み込みしてください」 |
| 位置情報の確認 | 星空を現在地に合わせるか選ぶ | 許可／位置情報なしで見る | 許可しなくても使える。取得できなければその旨を出して続ける |
| ミッション画面（トップ） | 宇宙を眺め、操作の入口 | 見出し「願いを星に、想いを地球へ。」、3D星空とイトカワ（名札に距離）、軌道の星、通信表示、下のパネル（01 送信／02 帰還／03 受け取り） | ネットなしのとき「ネットなし · 願いはこの端末の中で預かります」 |
| 01 送信（預ける画面） | 願いを預ける | 60字の入力欄、帰還が始まる日（任意・翌日〜1年後）、星を軌道へ送る | 空欄→聞き返し。軌道が30個→預けず入力を残す。日付が範囲外→理由を出す |
| 02 帰還 | 1つ帰す | 振る／タップで帰還 | 軌道が空→「すべての願いは地球にあります」。開始日前だけ→「○月○日から」。判断待ちがある→「先にカプセルを開いて」 |
| 03 受け取り（カプセル） | 帰ってきた願いと向き合う | 願いの言葉、預けた日、待っていた日数、イトカワまでの距離、届いた信号の数、3つの選択、Xで共有 | 選ばずに閉じてもカプセルは残る。保存に失敗→「もう一度お試しください」 |
| 回収記録 | 帰ってきた願いを見返す | 一覧、星座、応援リンク（信号が使えるときだけ）、あなたの記録（数とコピー）、削除・リセット | 削除とリセットは確認してから |
| 利用規約・プライバシー | 何を保存・送信するかを伝える | 保存、端末への保存、応援の信号、位置情報、外部サービス、ルール | — |
| 応援ページ（/signal） | 応援する人が信号を送る | 約束（名前も言葉も届かない）、光る星、信号を送る | リンク不正・未対応・混雑・今日はもう送った、をそれぞれ別の文言で |

## UIデザイン仕様

### 色

夜空の中で、金色を「願い・操作の中心」に使う。

| 役割 | 色 |
| --- | --- |
| 背景（夜空） | `#050812` 〜 `#101a25` のグラデーション |
| 主な操作・願いの光 | 金 `#e6c878`、`#edc45c`、光 `#fff1ce` |
| 本文 | `#e8e6dc`、`#e4e8df` |
| 補足 | `#98a7a9`、`#aebcba` |
| フォーカス | `#edcb8c` の2pxの枠 |

### 文字

- 本文：Zen Kaku Gothic New（ない端末は sans-serif）
- 願いの言葉・見出し：明朝（Yu Mincho、Hiragino Mincho ProN）
- 英字のラベル（WISH CAPSULE など）：Inter、字間を広げる
- 入力欄は16px以上（iPhone で拡大されないため）

### 操作

- 押せるものは44px以上の高さ
- 動きを減らす設定（prefers-reduced-motion）のときは、演出を止めるか短くする
- スマホの安全領域（ノッチ・ホームバー）を避ける
- 振る操作ができない端末には、必ずタップの代わりを用意する

### 文言

- 利用者を責めない。「まだ」「失敗」より「今でなくてもいい」「また明日」
- エラーは、何が起きたかと、どうすればよいかを1文で
