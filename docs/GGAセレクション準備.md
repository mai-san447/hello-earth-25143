# GGA セレクション準備

## 0. 方針（2026-10-11 メンターデーの助言から）

- 無理にスタートアップ型のビジネスモデルに当てはめず、**体験型の作品**として完成度を上げる
- プレゼンの**8割を世界観と体験**、2割を「それを実現する仕組み（収益）」に使う
- 作品の面白さを、ビジネスモデルの説明で消さない
- いちばん磨くのは、**願いが帰ってきた最後の30秒**
- AI を自由に使う部分（願いの見せ方）と、きちんと管理する部分（保存・位置・印刷）を分ける

位置づけ：**展示で出会い、帰還票を持ち帰り、アプリで続く**。

| | 役割 |
| --- | --- |
| 展示・イベント | 入口。その場で願いを預け、帰還票を受け取る |
| 帰還票（＋カプセル） | 持ち帰れる作品。QR から自分の星へ戻れる |
| アプリ | 続き。何日かあとに、願いが1つずつ帰ってくる |

GGA の審査基準（①課題の解像度 ②技術への主体性 ③ディストリビューション）は、プレゼンの各ページで答える（3. の表）。

## 1. 展示シナリオ3案

### 案A（本命）：星空に願いを預ける ― 科学館・宇宙イベント

| 項目 | 内容 |
| --- | --- |
| 体験 | ① スマホで QR を読む → ② 願いを書いて預ける（会場の大きな画面の星空に、金色の星が灯る）→ ③ スマホを振る → ④ カプセルが地球へ帰ってくる → ⑤ 帰還票がその場で感熱プリンターから「現像」される → ⑥ 持ち帰り、家で続きが帰ってくる |
| 会場の大きな画面 | 本物の星空。来場者が「星空に流す」を選んだ願いだけが、名前なしでふわっと浮かんでは消える（会場の中だけ。スタッフが見守る＝止めていた「みんなの星」を、展示の中で安全に使う） |
| 所要時間 | 1人 2〜3分 |
| 必要なもの | 大きな画面（またはプロジェクター）、PC、感熱プリンター（80mm）、ロール紙、QR の看板 |
| なぜ本命か | Why me（はやぶさ PM の取材）と「25143」の名前の由来がそのまま語れる。本物の星空・帰還・帰還票は、もう動いている |
| 導入先の例 | 科学館、プラネタリウム、宇宙関連のイベント、大学の公開イベント |

### 案B：願いを持ち帰る ― 商業施設・ポップアップ

| 項目 | 内容 |
| --- | --- |
| 体験 | 案A の短縮版（1分）。預ける → 振る → 帰還票と、サンプルカプセル（帰還票の半券「最初の小さな一歩」を入れるブレスレット）を受け取る |
| 物 | 帰還票、サンプルカプセル、キーホルダー |
| 導入先の例 | 商業施設の季節イベント（七夕・年末年始・新生活）、文具・雑貨店とのポップアップ |
| ねらい | 物販と組み合わせやすい。七夕や新年など「願いを書く季節」に合う |

### 案C：地域の願いをつなぐ ― 自治体・観光イベント

| 項目 | 内容 |
| --- | --- |
| 体験 | 地域の人と来た人が、その土地の夜空（その場所の緯度経度で描く本物の星空）に願いを預ける。会場の画面に、地域の願いが浮かぶ |
| 物 | その土地の名前と星空が入った帰還票 |
| 導入先の例 | 星空の見える町の観光イベント、地域の祭り、移住・関係人口のイベント |
| ねらい | 「本物の星空・今いる場所」という技術が、地域ごとの体験にそのまま使える |

### 共通して使えるもの：アーティストとの共創

どの案でも、帰還票の絵や会場の画面の見せ方を、アーティストと一緒に作れる（例：星の絵の柄をアーティストが描く、会場の映像演出）。願いの**見せ方**は自由に作ってよい部分で、願いの**中身**の扱い（保存しない・送らない）は変えない。

## 2. 帰還後に持ち帰る「帰還票」のデザイン（決定案）

今の帰還票（感熱紙 80mm、白黒、576 ドット）をもとに、次のように決める。

```
┌────────────────────────────┐
│ MORUNE 25143        25143-0007-03 │  ← 作品名と番号
│ ┌──────────────────────┐ │
│ │   星空のドット絵（ガチャ）        │ │  ← 夕方の一番星／満天の星／夜明け／流れ星（レア）
│ │   地面に立つ人のシルエット        │ │     （次期：自分のドット絵に置き換えられる #31）
│ └──────────────────────┘ │
│     パンを一から焼いてみる          │  ← 願いの言葉（大きく。外すこともできる）
│ 2026.09.12 → 2026.10.11 · 25143まで 約2.5億km │  ← 預けた日 → 帰ってきた日、距離
│              ▣ QR                    │  ← 自分の星へ戻れる
│ ✂ - - - - - - - - - - - - - - - - - │
│ 最初の小さな一歩                     │  ← 半券。切ってカプセルに入れられる
│ 近くのパン教室を調べる               │
│ 距離：NASA/JPL Horizons              │
│ 番号は作品の中だけのもので、本物の星の名前ではありません │
└────────────────────────────┘
```

決めたこと：
- 文字は最小限。あいさつ・説明の文は入れない（2026-10-07 決定のまま）
- 画面では「帰還票が現像されました」と出し、紙が上から少しずつ出てくるように見せる（感熱紙の「現像」）
- 展示では、その場で感熱プリンターから印刷して手渡す。アプリでは画像を保存してシェアする
- 半券「最初の小さな一歩」は、切り取ってサンプルカプセル（ブレスレット）に入れられる大きさにする（案B）。カプセルに入らない場合は、カプセル用の小さい紙を別に用意する（試作で確かめる）
- 商品と紙には「25143」・星・MORUNE だけ。はやぶさ・JAXA の名前や形は入れない

### GGA 本番（5分）に縮めるとき

1（0:40）→ 2（0:20）→ 3 デモ（2:00）→ 4＋5（0:50）→ 6（0:20）→ 7（0:30）→ 8（0:20）。

### デモで見せる「最後の30秒」

1. カプセルが地球に着く
2. 願いの言葉が、星空からふわっと降りてくる
3. 「30日間、あなたを待っていました」
4. 「想いを受け取る」→ 帰還票が上から少しずつ現像される（会場では、プリンターから本物の紙が出てくる）

デモは、見本の願いを入れた端末で行う。念のため録画も用意する（時間の早送りは作らない）。

## 4. 実現の仕組み（収益モデル・1枚）

**個人からはお金を取らない。体験を届ける場と、持ち帰る物で成り立たせる。**

| 収益の柱 | 誰から | 中身 | 価格の仮説（未検証） |
| --- | --- | --- | --- |
| 展示の導入 | 科学館・商業施設・自治体 | 案A〜C の体験一式（画面の設定、プリンター、運営の手順）を期間で貸す | 1回の出展ごとの料金 |
| 物販 | 来場者 | サンプルカプセル（ブレスレット）、キーホルダー、帰還票の台紙 | 数百円〜千円台 |
| コラボ | アーティスト・ブランド | 星の絵の柄・会場の演出を共同で作る。限定の帰還票 | 企画ごとに分配 |

前提として決めていること：
- アプリは無料のまま（願いは端末の中。データの守りやサポートの体制がないうちは、アプリにはお金をもらわない）
- 物販の前に、特定商取引法の表示を作る。はやぶさの名前や形を商品に入れる場合は JAXA に相談する（入れなければ相談なしで進められる見込み）
- MORUNE は商標登録済み（区分は要確認）

検証のしかた：GGA の交流会で、帰還票の印刷体験と物を実際に見せ、「どこに置けるか」「いくらなら買うか」を聞く。

## 5. 星空に願いが浮かぶ表現（試作）

アプリに入れる（ブランチ `feat/floating-wishes`、Codex 実装、本人確認後に公開）：
- 自分の星に触れると、その願いの言葉が2〜3秒ふわっと浮かんで消える
- 開いて数秒後に、預けている願いのうち1つの言葉が、一度だけ淡く浮かぶ（偶然の出会い）
- 帰還の瞬間、願いの言葉が星空から降りてきてから、帰還カードが開く
- 帰還票は「現像されました」と出し、紙が上から少しずつ現れる

展示の大きな画面（会場の中だけで、来場者の願いが浮かぶ）は、GGA までに作る。
