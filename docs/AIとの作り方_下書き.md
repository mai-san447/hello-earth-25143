# AI に任せたこと、自分で決めたこと（下書き）

> これは Claude が作業報告から拾った下書きです。発表で使う前に、本人の言葉に直してください。日付は作業報告の日付です。

## 一言で

**コードを書く手は AI に任せた。何を作り、何をやめ、何を守るかは、わたしが決めた。** 決めるときは、実際の画面を見て、触って、数字で確かめた。

## AI に任せたこと

| 何を | どう任せたか |
| --- | --- |
| コードを書く | Claude と Codex に書かせた。夜のあいだに試作させ、朝に本人が見て決める進め方もした（育つ願い、みんなの星空と見守り） |
| レビュー | Claude と Codex に、互いのコードをレビューさせた。公開前には、別の AI に「正しさ・セキュリティ」「使いやすさ・倫理」などの観点を分けてレビューさせた |
| 調べもの・計算 | 類似サービス、権利（はやぶさ・25143）、星の位置の計算、星の席や確率のシミュレーション |
| 資料の下書き | 企画書、設計書、スライドの下書き、デモの録画、想定問答 |
