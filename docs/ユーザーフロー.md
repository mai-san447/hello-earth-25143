# MORUNE 25143 ユーザーフロー

更新：2026-09-30　機能の ID は `docs/機能要件.md`、状態の動きは `docs/状態設計.md`

## 1. 本人：入院前（家、ネットあり）

```mermaid
flowchart TD
    A[アプリを開く<br/>ホーム画面に追加] --> B[位置情報を許可するか選ぶ<br/>F13・任意]
    B --> C[01 送信：願いを預ける F01]
    C --> D{帰還が始まる日を決める？}
    D -->|決める| E[退院予定の日を選ぶ F06]
    D -->|決めない| F[すぐ帰還の候補になる]
    E --> G[星がイトカワの軌道に浮かぶ]
    F --> G
    G --> H[回収記録から応援リンクを送る<br/>F10・任意]
```

## 2. 本人：入院中（病室、ネットなし）

```mermaid
flowchart TD
    A[ホーム画面から開く<br/>保存した画面で開く F08] --> B[ネットなし · 願いはこの端末の中で預かります]
    B --> C[思いついた願いを足す F01]
    B --> D[星が回っているのを眺める<br/>信号が届いた星は明るい F10]
    B --> E{帰還が始まる日の前？}
    E -->|前| F[振っても帰らない<br/>○月○日から、と案内 F06]
    E -->|過ぎた| G[帰還できる F02]
```

休憩室の Wi-Fi につながったら、届いた応援の信号を取りに行く（F10）。

## 3. 本人：退院後（1つずつ向き合う）

```mermaid
flowchart TD
    A[02 帰還：振る／タップ F02] --> B[はやぶさが1つ連れ帰る]
    B --> C[03 受け取り：カプセルを開く]
    C --> D[預けた日・待っていた日数 F04<br/>イトカワまでの距離 F05<br/>届いた信号の数 F10]
    D --> E{どうする？ F03}
    E -->|想いを受け取る| F[星座に加わる F09]
    E -->|軌道へ戻す| G[また軌道へ<br/>5回目にやさしい一言 F07]
    E -->|アーカイブに保存| H[回収記録へ F11]
    E -->|選ばずに閉じる| I[カプセルは手元に残る<br/>次に開いたら再開]
    G --> A
    I --> C
```

## 4. 応援する人

```mermaid
flowchart TD
    A[応援リンクを受け取る<br/>/signal?to=軌道ID] --> B{受け付けている？}
    B -->|いいえ| C[まだ受け付けていません]
    B -->|はい| D[信号を送る／振る]
    D --> E[星が少し明るくなる<br/>また明日送れます]
```

応援する人には、願いの中身も持ち主の名前も見えない。持ち主は、願いが帰ってきた日に「届いた信号の数」だけを受け取る。
