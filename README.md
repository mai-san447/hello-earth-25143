# 25143 — HELLO EARTH

HACK SONIC 2026秋「宇宙をHACKせよ」提出作。小惑星25143イトカワのサンプルリターンから着想した、願いの帰還体験です。

テキストまたは音声入力でやりたいことを文字として預け、スマホを振ると1件だけ帰還します。内容を確認して「これやろう」「いまはいいや」「もう用済み」「既に対応済み」から選ぶと、はやぶさがイトカワへ戻ります。動きのセンサーを使えないときはボタンでも帰還できます。

願いの文字はIndexedDBでその端末のブラウザ内に保存します。アプリに録音機能はありません。音声入力はブラウザの音声認識機能を使い、その処理方法はブラウザに依存します。以前の版で保存した録音は、その願いが帰還したときに再生できます。端末間同期やバックアップはありません。
