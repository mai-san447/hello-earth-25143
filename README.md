# 25143 — HELLO EARTH

HACK SONIC 2026秋「宇宙をHACKせよ」提出作。小惑星25143イトカワのサンプルリターンから着想した、願いの帰還体験です。

入力欄にやりたいことを預け、スマホを振ると1件だけ帰還します。文字入力にはスマホのキーボードに備わる音声入力も使えます。内容を確認して「これやろう」「いまはいいや」「もう用済み」「既に対応済み」から選ぶと、はやぶさがイトカワへ戻ります。動きのセンサーを使えないときはボタンでも帰還できます。

願いの文字はIndexedDBでその端末のブラウザ内に保存します。アプリに録音・音声認識機能はありません。以前の版で保存した録音は、その願いが帰還したときに再生できます。端末間同期やバックアップはありません。
