# 25143 — HELLO EARTH

HACK SONIC 2026秋「宇宙をHACKせよ」提出作。小惑星25143イトカワのサンプルリターンから着想した、願いの帰還体験です。

テキストか30秒以内の声でやりたいことを預け、スマホを振ると1件だけ帰還します。内容を確認して「これやろう」「いまはいいや」「もう用済み」「既に対応済み」から選ぶと、はやぶさがイトカワへ戻ります。動きのセンサーを使えないときはボタンでも帰還できます。

願いと音声はIndexedDBでその端末のブラウザ内に保存し、外部へ送信しません。端末間同期やバックアップはありません。
