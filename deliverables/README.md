# MORUNE 25143 デザイン納品物

## 公開URL

https://morune-25143.morune-25143.workers.dev/

## ファイル

- `morune-cd-cover.svg`: ミニCDジャケット表紙用。1200 x 1200 px。
- `morune-keyholder-front.svg`: キーホルダー表面。63 x 89 mm相当の縦長デザイン。
- `morune-keyholder-back.svg`: キーホルダー裏面。63 x 89 mm相当。QRコード配置欄あり。
- `morune-presentation.html`: 6枚構成の6分プレゼン資料。ブラウザーで開いて全画面表示できます。

## 印刷時の注意

- キーホルダーの指定寸法は縦89 mm x 横63 mmとして作成しています。
- 入稿時は上下左右に2〜3 mmの塗り足しを追加してください。
- QRコードは実際のQR画像に差し替えてから入稿してください。現在の裏面SVGには誤リンク防止のプレースホルダーを置いています。
- 文字をアウトライン化する場合は、入稿先の印刷仕様に合わせてください。

## 6分発表の使い方

1. `morune-presentation.html` をブラウザーで開く
2. ブラウザーを全画面表示
3. 1枚目から順に表示
4. 3枚目のデモで公開URLを開く

スライドは「問いかけ → はやぶさとの接続 → デモ → UX → 技術 → 締め」の6枚です。
